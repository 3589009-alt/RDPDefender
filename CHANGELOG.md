# Changelog

## 1.3.7 — 2026-11-17

- Список «Успешные» больше не ограничивается 500 записями и не удаляет старые
  IP автоматически: успешное подключение хранится бессрочно.
- Порядок обработки закреплён: чёрный/белый списки → успешные → уже
  заблокированные → остальные правила.
- Уже заблокированный IP отклоняется до проверок режима и типа входа.
- Очищены рабочие списки блокировок, попыток и успешных подключений
  (белый и чёрный списки настроек сохранены).

## 1.3.6 — 2026-11-16

- Исправлено отображение `LAN` в колонке «Страна» для локальных IP после
  открытия панели данных.

## 1.3.5 — 2026-11-16

- В списках «Защита», «Попытки» и «Успешные» добавлена отдельная колонка
  **«Страна»** рядом с IP; значение подтягивается из whois для видимых строк.
- Колесо мыши прокручивает контрол под курсором, а не тот, что в фокусе.
- На вкладке «Успешные» — панель данных IP с whois, как в блоках и попытках.

## 1.3.4 — 2026-11-16

- На вкладке **«Успешные»** появилась панель данных по выбранному IP: успешные
  входы, агрегаты 4625, состояние блокировки, PTR, страна, сеть, организация,
  ASN, abuse-контакт и сырой whois.

## 1.3.3 — 2026-11-16

- Добавлена вкладка **«Успешные»** между «Попытки» и «Журнал»: IP успешных
  RDP-подключений, число входов, источник, пользователь, станция и состояние защиты.
- Автоматическое добавление успешных IP в белый список заменено отдельным списком
  успешных подключений; настройка **«Не блокировать успешные подключения»**
  включает и выключает защиту.
- Чёрный и белый списки проверяются первыми; постоянный чёрный список имеет
  приоритет над белым и над успешными подключениями.

## 1.3.2 — 2026-11-16

- В списках блокировок и попыток появилась панель «Данные атакующего»:
  PTR, страна, сеть, организация, ASN, abuse-контакт, агрегаты по IP и сырой whois.
- Клик по плитке «Активные блокировки» открывает вкладку «Защита»,
  по плитке «Неудачных входов» — «Попытки».
- Клик по плитке «Режим» переключает «Блокировка» / «Наблюдение».
- GitHub-установщик остаётся неподписанным; подписанный web-установщик
  с галочкой установки корневого сертификата публикуется только на kmadmin.ru.

## 1.3.1 — 2026-11-14

- Под селектором способа блокировки добавлены пояснения об особенностях
  и ограничениях брандмауэра Windows, WinDivert и политик IP.
- Веб-установщик с kmadmin.ru подписан и предлагает опциональную установку
  корневого сертификата; GitHub-установщик намеренно не подписан и не содержит
  корневой сертификат.

## 1.3.0 — 2026-11-14

- Добавлен встроенный обновлятор: проверка GitHub Releases, скачивание установщика,
  проверка SHA-256 и запуск обновления.
- 35 автоматических проверок.

## 1.2.0 — 2026-11-14

- После успешного RDP-входа сбрасываются счётчики неудачных попыток и подключений
  для IP клиента, снимается активная блокировка.
- Добавлена настройка **«Успешные входы — в белый список»**.
- Добавлена поддержка Microsoft RD Gateway (HTTP/HTTPS): события 304 учитываются
  как неудачные входы, 302 сбрасывает счётчики; IP клиента берётся из журнала шлюза.
- 34 автоматические проверки.

## 1.1.0 — 2026-11-14

- Добавлен установщик Windows (`RDP-Defender-Setup-1.1.0.exe`): установка в
  `C:\Program Files\RDP Defender`, служба, ярлыки, запись в «Программы и компоненты»,
  обновление поверх старой версии и деинсталлятор.
- Добавлен раздел **«Попытки»**: последние неудачные входы (4625) с IP, пользователем,
  типом входа, рабочей станцией и результатом.
- Добавлен учёт событий **261** (RDP-подключения до аутентификации). Источник IP
  определяется по активным TCP-подключениям; при превышении общего порога
  (по умолчанию 50 за 10 минут) блокируются активные внешние источники.
- Версия поднята до 1.1.0, обновлены интерфейс, документация и скриншоты.
- 31 автоматическая проверка.

## 1.0.0 — 2026-11-13

- Первый выпуск: служба Windows, мониторинг 4625, блокировка через брандмауэр,
  WinDivert и локальные политики IPsec, тёмный GUI, белый/чёрный списки,
  журнал, самопроверка.
