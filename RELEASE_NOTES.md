# RDP Defender 1.3.6

Защита RDP от подбора паролей для Windows x64.

## assets

- `RDP-Defender-Setup-1.3.6.exe` — установщик для GitHub (не подписан);
- `RDP-Defender-1.3.6-win-x64.zip` — portable-версия;
- `SHA256SUMS.txt` — контрольные суммы.

Подписанный веб-установщик с опциональной установкой корневого сертификата:
<https://kmadmin.ru/downloads/RDP-Defender-Setup-Web.exe>.

## Основное

- в списках «Защита», «Попытки» и «Успешные» — отдельная колонка **«Страна»**
  рядом с IP (whois для видимых строк, асинхронно и с кэшем);
- на вкладке «Успешные» — панель данных IP с агрегатами, блокировкой и whois;
- колесо мыши прокручивает контрол под курсором, а не находящийся в фокусе;
- успешные IP ведутся отдельным списком; настройка **«Не блокировать успешные
  подключения»** управляет защитой;
- чёрный и белый списки проверяются первыми, чёрный список приоритетнее;
- на вкладках «Защита» и «Попытки» — панель данных атакующего и whois;
- клики по плиткам «Активные блокировки», «Неудачных входов» и «Режим»;
- подписанный web-установщик с галочкой установки корня;
- GitHub-установщик намеренно не подписан.

## Подпись

Веб-установщик с kmadmin.ru подписан локальным код-сайнинг сертификатом
**KMV Admin** (CA **kmadmin.ru**) и предлагает опциональную установку корневого
сертификата. GitHub-установщик не подписан и не содержит корневой сертификат.

Корневой сертификат: <https://kmadmin.ru/downloads/kmadmin-root.cer>.

## Требования

- Windows 10/11 или Windows Server 2016+ x64;
- права администратора;
- включённый аудит неудачных входов для событий 4625;
- для WinDivert — загружаемый драйвер (входит в комплект).
