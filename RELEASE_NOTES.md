# RDP Defender 1.3.2

Защита RDP от подбора паролей для Windows x64.

## assets

- `RDP-Defender-Setup-1.3.2.exe` — установщик для GitHub (не подписан);
- `RDP-Defender-1.3.2-win-x64.zip` — portable-версия;
- `SHA256SUMS.txt` — контрольные суммы.

Подписанный веб-установщик с опциональной установкой корневого сертификата:
<https://kmadmin.ru/downloads/RDP-Defender-Setup-Web.exe>.

## Основное

- в списках блокировок и попыток появилась панель «Данные атакующего»:
  PTR, страна, сеть, организация, ASN, abuse-контакт, агрегаты по IP и сырой whois;
- клик по плитке «Активные блокировки» открывает вкладку «Защита»;
- клик по плитке «Неудачных входов» открывает вкладку «Попытки»;
- клик по плитке «Режим» переключает «Блокировка» / «Наблюдение»;
- под селектором способа блокировки — пояснения об особенностях методов;
- встроенный обновлятор с проверкой GitHub Releases и SHA-256;
- мониторинг неудачных входов (Security 4625);
- учёт RDP-подключений (событие 261) с блокировкой при превышении порога;
- сброс счётчиков и снятие блокировки после успешного входа;
- поддержка Microsoft RD Gateway (HTTP/HTTPS, события 302/304);
- брандмауэр Windows, WinDivert или локальные политики IPsec.

## Подпись

Веб-установщик с kmadmin.ru подписан локальным код-сайнинг сертификатом
**KMV Admin** (CA **kmadmin.ru**) и предлагает опциональную установку корневого
сертификата. GitHub-установщик намеренно не подписан и не содержит корневой
сертификат.

Корневой сертификат: <https://kmadmin.ru/downloads/kmadmin-root.cer>.

## Требования

- Windows 10/11 или Windows Server 2016+ x64;
- права администратора;
- включённый аудит неудачных входов для событий 4625;
- для WinDivert — загружаемый драйвер (входит в комплект).
