# RDP Defender 1.3.3

Защита RDP от подбора паролей для Windows x64.

## assets

- `RDP-Defender-Setup-1.3.3.exe` — установщик для GitHub (не подписан);
- `RDP-Defender-1.3.3-win-x64.zip` — portable-версия;
- `SHA256SUMS.txt` — контрольные суммы.

Подписанный веб-установщик с опциональной установкой корневого сертификата:
<https://kmadmin.ru/downloads/RDP-Defender-Setup-Web.exe>.

## Основное

- новая вкладка **«Успешные»**: IP успешных RDP-подключений, число входов,
  источник, пользователь, станция и состояние защиты;
- успешные IP больше не добавляются в белый список: для них ведётся отдельный
  список, а настройка **«Не блокировать успешные подключения»** управляет защитой;
- чёрный и белый списки проверяются первыми; чёрный список приоритетнее;
- в списках блокировок и попыток — панель «Данные атакующего» с PTR, страной,
  сетью, организацией, ASN, abuse-контактом, агрегатами по IP и сырым whois;
- клик по «Активные блокировки» открывает «Защиту», по «Неудачных входов» — «Попытки»;
- клик по «Режим» переключает «Блокировка» / «Наблюдение»;
- встроенный обновлятор с проверкой GitHub Releases и SHA-256;
- мониторинг неудачных входов (Security 4625), учёт 261 и RD Gateway 302/304;
- брандмауэр Windows, WinDivert или локальные политики IPsec.

## Подпись

Веб-установщик с kmadmin.ru подписан локальным код-сайнинг сертификатом
**KMV Admin** (CA **kmadmin.ru**) и предлагает опциональную установку корневого
сертификата. GitHub-установщик намеренно не подписан и не содержит корневой
сертификат.

Корневой сертификат: <https://kmadmin.ru/downloads/kmadmin-root.cer>.

## Требования

- Windows 10/11 или Windows Server 2016+ x64;
- права администратора;
- включённый аудит неудачных входов для событий 4625;
- для WinDivert — загружаемый драйвер (входит в комплект).
